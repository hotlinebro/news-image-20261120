## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The poster itself is drawn by `render.py` (kept with the build notes, not the entry): `python3 render.py` writes `entry.png`, and `main.ts` copies that file to `/output`.
